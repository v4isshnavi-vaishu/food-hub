# 🍽️ Restaurant Website

## 📌 Project Description
The Restaurant Website is a responsive and attractive webpage developed using **HTML and CSS**. It is designed to showcase a restaurant's food menu, special offers, customer reviews, and contact information in a simple and user-friendly way.

The website provides visitors with an easy way to explore food items, check prices, learn about special offers, and find restaurant details.

## 🎯 Features

- **Home Section:** Attractive hero section with a welcome message and background image.
- **Food Menu:** Displays different food items with images, descriptions, and prices.
- **Special Offers:** Highlights discounts and exciting restaurant deals.
- **Customer Reviews:** Displays customer feedback and ratings.
- **Contact Section:** Provides restaurant location, phone number, email, and opening hours.
- **Navigation Bar:** Easy navigation between different website sections.
- **Responsive Design:** Supports desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

- HTML5 – To create the structure of the webpage.
- CSS3 – To design and style the webpage.
- Unsplash – For food and restaurant images.
